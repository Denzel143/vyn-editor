    Simulator VynWatch

    Jalankan program Lua di editor pada perangkat virtual: OLED 128×64, pad touch, encoder, dan sensor dummy.

    Tulis DSL watch face secara manual atau impor dari paket ZIP. Verifikasi dan pratinjau memakai aturan interpreter yang sama dengan firmware (chatbox_esp32s3.ino); tombol unggah aktif otomatis jika semua isian lolos verifikasi.

    Editor teks DSL

    ZIP berisi record.json dan face.dsl di root (tanpa thumbnail: aplikasi Native menggambar pratinjau langsung dari DSL).

    Editor visual

    Klik tombol elemen (atau seret ke layar) untuk menambah. Geser elemen untuk memindah, tarik titik pegangan untuk mengubah ukuran. DSL teks ditulis otomatis, dan perubahan di editor teks ikut tampil di sini. Menyunting secara visual menulis ulang DSL (komentar tidak dipertahankan). Papan ketik di kanvas: panah = geser (Shift = 8 px), Delete = hapus, Ctrl+Z / Ctrl+Y = urungkan / ulangi, Ctrl+D = gandakan.

    Baterai, BLE, WiFi, dan notifikasi mengikuti kontrol di overlay pratinjau.
